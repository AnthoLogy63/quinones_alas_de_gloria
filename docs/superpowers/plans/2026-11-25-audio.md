# Incorporación de audio

> Ejecución en la carpeta actual, solicitada por el usuario. Alcance: descargar
> la selección de sonidos acordada y colocarla en el juego.

**Objetivo:** incorporar 35 clips con procedencia y licencias, enlazar el motor
y los eventos que ya existen, y preparar el audio de menú sin construir pantallas.

**Arquitectura:** archivos por pantalla o entidad siguiendo Assets; AudioDeNivel
escucha EventosDeJuego sin modificar las reglas; AudioDeMenu ofrece métodos
para botones y un prefab preparado. Ningún servicio persistente global.

**Restricciones:** conservar el audio anterior y el Unity declarado 6000.3.23f1;
validar en una copia temporal con el editor instalado 6000.6.0f1; conservar
visuales y navegación de las interfaces de otras áreas.

- [x] Descargar desde Kenney y OpenGameArt; guardar autor, licencia y cambios.
- [x] Preparar WAV para efectos, OGG para música y metadatos estables.
- [x] Sustituir la referencia del motor en prefab, escena de pruebas y generador.
- [x] Verificar que falta el controlador de eventos mediante una prueba en Unity.
- [x] Añadir AudioDeNivel y AudioDeMenu; configurar las escenas de prueba y Nivel_01.
- [x] Probar fuentes independientes, finalización, reactivación y desuscripción.
- [x] Decodificar los 35 archivos y verificar metadatos, referencias y licencias.

**Revisión:** no avisar combustible bajo durante el tutorial de consumo cero;
no duplicar efectos al reactivar; detener música al finalizar; ignorar clips
sin asignar; no disparar impactos extra durante invulnerabilidad.
